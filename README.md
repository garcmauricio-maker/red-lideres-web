# Red de Líderes · versión web

Versión web de la app de registro, para líderes con **iPhone** (o cualquier celular sin el APK).

**Instalar en iPhone:** abrir el enlace en **Safari** → botón **Compartir** → **Agregar a inicio**.

Funciona sin señal y sube los registros sola al recuperar la conexión. Usa la misma base de datos que el APK.
